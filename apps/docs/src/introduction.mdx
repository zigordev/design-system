# zigordev design system

One brand for every zigordev app: a lavender accent on an anthracite base, the precise corners, one typeface, and the same components, behaviour, accessibility, spacing and motion everywhere. The apps differ only in how they compose the components.

## Modes

Dark is the default. Use the toolbar to switch the mode; in an app, the same value is the `data-mode` attribute on the root element.

| `data-mode` | Result |
| --- | --- |
| none, or `dark` | Dark |
| `light` | Light |
| `system` | Follows the system's light or dark setting |

## Packages

- `@zigordev/tokens`: the design tokens, built from DTCG 2025.10 sources into CSS custom properties.
- `@zigordev/css`: the tokens, a small reset, base styles and every component style, in cascade layers, as one file.
- `@zigordev/react`: React components on Base UI, styled by `@zigordev/css`.
- `@zigordev/icons`: the curated Lucide set, as React components and an SVG sprite.
- `@zigordev/email`: email components on React Email, themed from the tokens.

## Rules every component follows

- Component CSS uses role tokens only. A test rejects raw colours, lengths and durations.
- Every text, border and focus pairing meets WCAG 2.2 AA in both modes.
- Interactive components follow their WAI-ARIA pattern through Base UI and are tested with the keyboard and axe in both modes.
- Components hold no copy. Labels come in as props, translated by the app.
