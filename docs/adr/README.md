# Decision records

Each significant decision for the design system gets one short record: context, decision, consequences and the alternatives considered. Records are numbered, an accepted record is never edited, and a new record supersedes an old one by naming it. Decisions for the whole estate live in toolkit's records.

To add one, copy [template.md](template.md) to `NNNN-short-title.md` with the next free number, and add it to this index in the same pull request.
